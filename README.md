## Projects

### Structural Damage Classification with Deep Learning (2026)
Research project carried out under the supervision of
a university professor. The project focuses on the automated
classification of structural damage, including cracks, using computer vision and
deep learning. It covers image preprocessing, data augmentation, class imbalance
handling, and training neural network models for both binary and multiclass
classification.

- **Tech:** Python, PyTorch, Pillow, EfficientNetV2-M, ConvNeXt-Tiny
- **Areas:** Artificial intelligence, computer vision, data analysis, applied research
- *Source code is stored in a private repository.*

### Intelligent Academic Management App (2025)
Cross-platform application developed as a course project.
It is designed to improve academic organization and study time management, with
dynamic assessment prioritization, study session tracking, reminders,
statistical analysis, and academic risk detection. It also integrates generative
AI through the Google Gemini API to summarize study materials.

- **Tech:** Kotlin, Kotlin Multiplatform, Compose, Google Gemini API, JSON
- **Areas:** Software engineering, object-oriented programming, statistical analysis, generative AI
- *Source code is stored in a private repository.*
